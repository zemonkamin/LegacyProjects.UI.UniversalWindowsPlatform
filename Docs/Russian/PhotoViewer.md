# PhotoViewer

`PhotoViewer` открывает полноэкранный просмотрщик удалённых фотографий на тёмном фоне. Поддерживаются перелистывание через `FlipView`, счётчик фотографий, до девяти переключаемых индикаторов, масштабирование и перемещение изображения, а также системные действия **«Сохранить»** и **«Поделиться»**. Просмотрщик открывается **из C#**, а не размещается непосредственно в XAML.

Реализация рассчитана на UWP (Windows 10 SDK 14393 / C# 6) и учитывает особенности интерфейса на ПК и Windows Mobile.

## Быстрый старт

Добавьте кнопку на существующую страницу:

```xml
<Button Content="Открыть фотографии" Click="ViewPhotos_Click" />
```

В code-behind страницы:

```csharp
using System;
using System.Collections.Generic;
using LegacyProjects.UI.UniversalWindowsPlatform.Controls;
using LegacyProjects.UI.UniversalWindowsPlatform.Models;
using Windows.UI.Xaml;

private async void ViewPhotos_Click(object sender, RoutedEventArgs e)
{
    var photos = new List<PhotoViewerItem>
    {
        new PhotoViewerItem
        {
            Url = "https://example.com/images/photo1.jpg",
            Title = "Первая фотография",
            FileName = "photo1.jpg"
        },
        new PhotoViewerItem
        {
            Url = "https://example.com/images/photo2.jpg",
            Title = "Вторая фотография",
            FileName = "photo2.jpg"
        }
    };

    await PhotoViewer.ShowAsync(photos, 0, new PhotoViewerOptions
    {
        Title = "Фотографии",
        SaveLabel = "Сохранить",
        ShareLabel = "Поделиться"
    });
    // Выполнение продолжится после закрытия просмотрщика.
}
```

Замените демонстрационные адреса на настоящие ссылки на изображения, доступные напрямую или через предусмотренный сервером механизм авторизации. `ShowAsync` принимает `IEnumerable<PhotoViewerItem>`; `selectedIndex` — индекс с нуля. Возвращаемый `Task` завершается **после закрытия** просмотрщика, а не сразу после открытия.

## PhotoViewerItem

Пространство имён: `LegacyProjects.UI.UniversalWindowsPlatform.Models`.

| Свойство | Тип | Назначение |
|---|---|---|
| `Url` | `string` | **Обязательное.** Абсолютный URL с протоколом `http://` или `https://`. |
| `Title` | `string` | Необязательные данные. В текущей реализации заголовок отдельной фотографии **не отображается**. |
| `FileName` | `string` | Предлагаемое имя при сохранении; недопустимые символы заменяются, а расширение определяется по формату загруженного файла. |
| `Preview` | `ImageSource` | Необязательная миниатюра, которая отображается до загрузки полноразмерной фотографии. |

Для миниатюры можно использовать локальный ресурс, хотя полноразмерный `Url` должен быть сетевым:

```csharp
using Windows.UI.Xaml.Media.Imaging;

var photo = new PhotoViewerItem
{
    Url = "https://example.com/images/fullsize.jpg",
    Preview = new BitmapImage(new Uri("ms-appx:///Assets/preview.jpg")),
    FileName = "fullsize.jpg"
};
```

Элементы `null` и записи без абсолютного HTTP(S)-адреса исключаются. Если подходящих фотографий не осталось, просмотрщик не откроется. `selectedIndex` относится к исходному списку; если указанный элемент отфильтрован, используется индекс с ограничением по оставшемуся списку. Для полноразмерного изображения нельзя использовать `ms-appx:`, `file:`, `ms-appdata:` и локальные пути.

## PhotoViewerOptions

Пространство имён: `LegacyProjects.UI.UniversalWindowsPlatform.Models`.

| Свойство | Тип | По умолчанию / поведение |
|---|---|---|
| `Title` | `string` | Заголовок системной панели «Поделиться»; при пустом значении — `Фотография`. Не заголовок просмотрщика. |
| `SaveLabel` | `string` | Подпись кнопки сохранения; при `null` — `Сохранить`. |
| `ShareLabel` | `string` | Подпись кнопки отправки; при `null` — `Поделиться`. |
| `Referer` | `Uri` | Необязательный HTTP-заголовок `Referer` при загрузке изображения. |
| `ResolveUriAsync` | `Func<PhotoViewerItem, CancellationToken, Task<Uri>>` | Необязательная асинхронная функция получения фактического URL, например временной подписанной ссылки. |

`ResolveUriAsync` вызывается при загрузке фотографии и при запросе исходного файла для сохранения или отправки. Функция должна возвращать абсолютный HTTP(S)-адрес и учитывать переданный `CancellationToken`. Успешно полученный адрес повторно используется для этой фотографии около одной минуты, пока открыт просмотрщик. Даже при наличии обработчика исходный `PhotoViewerItem.Url` **обязан** быть корректным абсолютным HTTP(S)-адресом.

Пример указания `Referer` и подключения обработчика URL:

```csharp
using System;
using System.Threading.Tasks;

var options = new PhotoViewerOptions
{
    Referer = new Uri("https://example.com/"),
    ResolveUriAsync = (item, token) =>
    {
        token.ThrowIfCancellationRequested();
        // При необходимости замените на асинхронное получение подписанного URL.
        return Task.FromResult(new Uri(item.Url));
    }
};

await PhotoViewer.ShowAsync(photos, 0, options);
```

Встроенный HTTP-клиент не отправляет cookie. Для сайтов с защитой изображений может потребоваться `Referer` или подписанный URL; авторизация с помощью cookie этим API не реализована.

## Управление и навигация

- Фотографии можно листать жестом или через `FlipView`. Клавиши «Влево» и «Вправо» также переключают изображения, если текущее не увеличено. Переход за первый или последний элемент не выполняется.
- Двойное нажатие / двойной щелчок переключает масштаб между 1× и 2,5×. Внутренний `ScrollViewer` поддерживает увеличение и перемещение до 5×.
- Сверху показывается счётчик (`1 / 3` и т. п.). Снизу — до девяти точек с прокручиваемым окном индикаторов; нажатие на точку открывает соответствующее фото.
- Закрыть просмотрщик можно кнопкой **X** в левом верхнем углу, клавишей `Esc`, системной кнопкой «Назад» или нажатием на затемнённую область / за пределами самого изображения без увеличения.
- **«Сохранить»** открывает системный `FileSavePicker`, **«Поделиться»** — интерфейс Windows Share. Для обеих операций используется загруженный **исходный файл**, а не уменьшенная копия, показанная на экране.

Одновременно может быть открыт только один просмотрщик: открытие нового закрывает предыдущий.

## Публичный статический API

```csharp
await PhotoViewer.ShowAsync(photos);                   // Первое фото, настройки по умолчанию
await PhotoViewer.ShowAsync(photos, selectedIndex: 2); // Сразу третье фото

bool opened = PhotoViewer.IsOpen;
bool closed = PhotoViewer.TryCloseCurrent(); // false, если просмотрщик не был открыт
```

Метод `ShowAsync(IEnumerable<PhotoViewerItem> items, int selectedIndex = 0, PhotoViewerOptions options = null)` возвращает `Task`. `IsOpen` — статическое свойство `bool`, `TryCloseCurrent()` возвращает признак наличия открытого просмотрщика. Конструктор закрытый, поэтому `<ui:PhotoViewer />` в XAML добавлять не нужно и нельзя. Публичных событий смены фото и закрытия нет; завершение `await ShowAsync(...)` сообщает о закрытии.

## Загрузка и ограничения

- Изображения загружаются по HTTP(S) и кэшируются в `LocalCacheFolder/PhotoImages-v1`; актуальные файлы повторно используются до 24 часов. При очистке кэш ограничивается примерно **32 МиБ для Mobile** / **128 МиБ для ПК**.
- Максимальный размер загружаемого файла — **16 МиБ на Mobile** / **32 МиБ на ПК**. Количество одновременных скачиваний и декодирований ограничено.
- Для показа изображение уменьшается до максимальной стороны **1280 пикселей на Mobile** / **2560 пикселей на ПК**, с ограничением примерно **1 млн** / **4 млн пикселей** соответственно. При сохранении и отправке используются исходные данные без этого уменьшения.
- Изображения с некорректными или превышающими защитные пределы размерами отклоняются; на Mobile дополнительно отклоняются не-JPEG файлы с количеством пикселей более примерно **8,4 млн**.
- При переключении на следующее фото предыдущая загрузка отменяется; на загрузку выбранного изображения отведено около 30 секунд. Ошибки загрузки или декодирования показываются внутри просмотрщика.
- При экранном декодировании сейчас игнорируются EXIF-ориентация и управление цветом. Поддержка конкретных форматов также зависит от декодеров Windows.
- `SaveLabel` и `ShareLabel` позволяют локализовать подписи команд, но встроенные сообщения о состоянии и ошибках, запасной заголовок «Поделиться», подпись типа файла в окне сохранения, доступное имя кнопки закрытия и сообщение об ошибке открытия пока **жёстко заданы на русском языке**.

Для работы с удалёнными изображениями у приложения должно быть разрешение UWP `internetClient` в манифесте приложения. Библиотека не добавляет это разрешение в приложение автоматически.
